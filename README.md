Evaluación 2 - Software de Geolocalización con Python y Graphhopper

Descripción del Proyecto
Este proyecto es una aplicación interactiva desarrollada en Python que consume las API REST de Graphhopper (Geocoding y Routing) para calcular y mostrar la ruta óptima de viaje entre dos ciudades.

Funcionalidades
- Interfaz e interacción totalmente traducidas al español.
- Formateo de valores numéricos de distancia a un máximo de 2 decimales.
- Cálculo de tiempo formateado en horas, minutos y segundos.
- Opción de salida del programa ingresando 's' o 'salir'.
- Generación e impresión de la narrativa e instrucciones de viaje paso a paso en español.
Requisitos
- Python 3.x
- Librería `requests`
- API Key activa de Graphhopper

Instalación de dependencias
Ejecutar en la terminal o consola:
bash
pip install requests

Al iniciar el programa, ingrese el nombre de la ciudad u ubicación de Origen.

Ingrese el nombre de la ciudad u ubicación de Destino.

El programa mostrará el resumen de distancia, tiempo estimado y la narrativa detallada del viaje paso a paso.

Para terminar la ejecución en cualquier momento, escriba s o salir.
